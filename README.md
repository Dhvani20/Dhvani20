- 🎨 **Key Features**: Particle backgrounds, glassmorphism design, loading animations, dynamic typing, responsive layout, Vercel analytics.
- 🛠️ **Tech Stack**: React, Vite, Tailwind CSS, Three.js, Framer Motion, EmailJS.
- 🔗 **Demo**: [dhvani-portfolio-gold.vercel.app](https://dhvani-portfolio-gold.vercel.app)

### 🌿 [Plant-Disease Detection](https://github.com/Dhvani20/Plant-Disease)
> An intelligent machine learning web application that detects and classifies plant leaf diseases to assist agricultural health monitoring.
- 🔬 **Key Features**: Upload leaf images, run deep learning/machine learning models in Python, and instantly render disease diagnosis and cure advice on an interactive HTML dashboard.
- 🛠️ **Tech Stack**: Python, NumPy, Pandas, HTML, CSS, JavaScript.

### 📝 [Automated Question Paper Generator](https://github.com/Dhvani20/question_paper_system)
> An educational web platform designed to automate and streamline the creation of structured academic exams and tests.
- 🔐 **Key Features**: Admin dashboard panel, dynamic question uploads, custom test configuration (difficulty, subjects, marks allocation), automated document PDF compilation, and activity logging.
- 🛠️ **Tech Stack**: Python, Flask, HTML5, CSS3, SQL Database, File System.
